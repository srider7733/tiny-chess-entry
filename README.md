# Compact deterministic chess engine

A small deterministic Python chess engine for the [make.fun tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01). It reads the game state from `MAKEFUN_ENV_URL`, selects a legal move using fixed material and positional heuristics, and makes no model calls or random choices.

Run locally with Python 3.13 and the competition environment configured:

```bash
python3 main.py
```
